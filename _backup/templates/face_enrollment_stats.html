📖 How to Enroll

For Students

  1. Log in to your student dashboard
  2. Click on "Face Enrollment" section
  3. Allow camera access from your browser
  4. Click "Start Camera" button
  5. Capture your face 5 times from different angles
  6. System will process and enroll your face

Face Recognition Tips

  • ✓ Good lighting from the front
  • ✓ Face clearly visible and centered
  • ✓ Position 1-2 feet from camera
  • ✓ Remove glasses or accessories
  • ✓ Natural facial expression
  • ✓ Look directly at camera

For Teachers

  1. Go to "Face Attendance" page
  2. Select the subject/class
  3. Click "Start Camera" to begin
  4. System detects and marks attendance automatically
  5. Click "Stop" when done
  6. Attendance records are saved automatically
🔧 Raspberry Pi 3 Setup
# Install required dependencies
sudo apt-get update
sudo apt-get install python3-opencv python3-pip

# Install Python packages
pip3 install face-recognition
pip3 install flask
pip3 install numpy

# For Raspberry Pi Camera Module
pip3 install picamera

# Run the application
python3 app.py

Note: The application uses HOG (Histogram of Oriented Gradients) for face detection on Raspberry Pi to optimize for lower CPU usage. For better accuracy, consider upgrading to Raspberry Pi 4 or using a GPU accelerator.
